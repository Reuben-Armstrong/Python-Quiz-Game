# 🧠 Python Quiz Game

A beginner-friendly, terminal-based quiz game written in Python.
It tests the player with multiple-choice questions and tracks their score.

---

## 🎯 What It Does

- Displays 5 multiple-choice questions
- Each question has 4 answer options
- Accepts only valid answers (1–4)
- Tracks and displays the total correct answers

---

## 📋 Example Questions

- What is the capital city of France?
- How many legs does a spider have?
- What planet is known as the Red Planet?
- Who wrote Romeo and Juliet?
- What is the freezing point of water in Celsius?

---

## ▶️ How to Run

1. Make sure Python is installed (3.6 or newer).
2. Clone or download the script file.
3. Open terminal or IDE and run:

      python main.py
